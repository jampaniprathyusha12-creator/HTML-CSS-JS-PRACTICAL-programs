Introduction

CSS transitions allow property changes to happen smoothly over a specified period of time. CSS transformations allow elements to be moved, rotated, scaled or skewed.

Properties Used

transition: Creates a smooth change between styles.

transform: scale(): Changes the size of an element.

transform: rotate(): Rotates an element.

transform: translate(): Moves an element.

transform: skew(): Skews an element.
