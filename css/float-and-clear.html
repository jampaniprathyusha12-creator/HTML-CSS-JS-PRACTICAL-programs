Float and Clear Properties

Demonstration of CSS Float and Clear

1. Float Left

Float Left

This box is floated to the left using the CSS float property. The text flows around the floated element.

Float can be used to position an element to the left or right of its container.

2. Float Right

Float Right

This box is floated to the right using the CSS float property. The surrounding text flows around the element.

The float property can be used with values such as left and right.

3. Clear Property

Floated Box

This paragraph appears beside the floated element.

Clear Property:

This element uses clear: both. Therefore, it appears below both left and right floated elements.

Properties Used

float: left; moves an element to the left.

float: right; moves an element to the right.

clear: both; prevents an element from appearing beside floated elements.
