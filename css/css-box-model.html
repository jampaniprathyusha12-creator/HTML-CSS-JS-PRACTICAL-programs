CSS Box Model

Margin, Border, Padding and Content

Box Model Demonstration

Every HTML element is treated as a rectangular box. The CSS box model consists of content, padding, border and margin.

Content Area

Parts of the CSS Box Model

Margin

Margin creates space outside the border of an element.

Border

Border surrounds the padding and content.

Padding

Padding creates space between the content and the border.

Content

Content is the actual text or information inside the element.
