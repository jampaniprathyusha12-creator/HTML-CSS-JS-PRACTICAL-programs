CSS Overflow Properties

Demonstration of visible, hidden, scroll and auto

1. Overflow: Visible

This content demonstrates the visible overflow property. Extra content can extend outside the box.

2. Overflow: Hidden

This is a long content example. The overflow property is set to hidden, so content outside the box is clipped and cannot be seen.

3. Overflow: Scroll

This is a long content example used to demonstrate the scroll property. When the content is larger than the box, scrollbars are provided to view the remaining content.

4. Overflow: Auto

This is a long content example used to demonstrate the auto property. Scrollbars appear automatically when the content exceeds the size of the box.
