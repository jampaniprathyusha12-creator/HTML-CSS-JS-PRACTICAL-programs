Two-Column Webpage

Created using CSS Grid

Main Content

CSS Grid is a powerful layout system that allows us to create rows and columns easily.

In this example, the webpage is divided into two columns. The first column contains the main content and the second column contains a sidebar.

The layout automatically changes to a single column on smaller screens using a media query.
